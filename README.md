# Suggestion Box

**A full-stack social platform built around anonymous feedback, suggestions, and complaints.**

Suggestion Box is a web application I designed and developed independently in 2019. The main idea was to digitise the physical suggestion boxes commonly found in offices, giving companies and individuals a platform to collect feedback while allowing users to choose whether to identify themselves.

The application also included social networking features, allowing users to connect, communicate, and share content.

I spent approximately six months developing the application, from June to December 2019, after completing the freeCodeCamp curriculum between January and June. I built the application manually, using technical documentation and Stack Overflow to research problems and find solutions, and deployed it to Microsoft Azure.

## Features

### Feedback and Suggestion Boxes
- **Box creation:** Users could create dedicated pages for collecting suggestions, ideas, and complaints.
- **Anonymous submissions:** Senders could choose to hide their identity when submitting feedback. Anonymous submissions appeared under the name *Anonymous*.
- **Public and private boxes:** Box owners could choose whether submitted feedback was visible publicly or restricted to the box owner.

### User Accounts and Authentication
- **Registration and sign-in:** Dedicated registration and sign-in pages.
- **Email authentication:** Email-based account authentication.
- **Password security:** Password hashing to avoid storing passwords as plain text.
- **Password recovery:** A forgotten-password workflow to help users recover access to their accounts.
- **Profile customisation:** Users could change their profile pictures.

### Social Networking
- **User search:** Search for other users by name.
- **Friend requests:** Send and manage requests to connect with other users.
- **Direct messaging:** Communicate privately with other users.
- **Wall posts:** Publish pictures with captions on a personal wall.

## Technology Stack

- **Frontend:** React, HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Hosting:** Microsoft Azure

## Development Approach

I developed this application as a practical way to apply the programming knowledge I gained through self-study. The project required me to work across the frontend, backend, database, authentication, and deployment stages of a web application.

I used documentation and Stack Overflow as my main technical resources when solving problems and implementing features. Working independently on the project strengthened my ability to break complex requirements into smaller problems, reason through solutions, and apply programming concepts across different parts of a system.

## Deployment

The application was originally deployed on Microsoft Azure. I later discontinued the hosting because of the ongoing hosting costs while I was unemployed. The original live application is therefore no longer available.
